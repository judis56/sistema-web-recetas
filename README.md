# Sistema Web de Recetas

## Descripción
Aplicación web desarrollada para la gestión y visualización de recetas de cocina mediante una interfaz dinámica y una base de datos MySQL. El sistema permite registrar recetas, visualizar información e integrar imágenes para cada platillo.

## Funciones principales
- Registro y visualización de recetas
- Sistema CRUD (crear, leer, actualizar y eliminar)
- Integración de imágenes para recetas
- Gestión de usuarios
- Interfaz responsive y dinámica
- Conexión a base de datos MySQL

## Tecnologías utilizadas
- PHP
- MySQL
- AngularJS
- Bootstrap
- HTML5
- CSS3
- JavaScript
- WAMP Server

## Estructura del proyecto
- `assets/` → recursos visuales y estilos
- `forms/` → formularios del sistema
- `imagenes_recetas/` → imágenes de recetas
- `php/` → lógica backend y conexión a base de datos
- `index.html` → página principal

## Objetivo del proyecto
Desarrollar una aplicación web funcional que permita administrar recetas de manera sencilla y dinámica, aplicando conocimientos de desarrollo web, bases de datos y diseño de interfaces.
